ch0–ch6 → uo[7:1]  ·  ch7–ch14 → uio[7:0]  ·  ch15 → uo[0], only when ctrl.uart_tx_en is cleared (which also drops the serial link, so the UI keeps it on)
Servo mode maps 0x00 → 1.000 ms, 0x80 → 1.500 ms, 0xFF → 1.996 ms inside a 20 ms frame. Moving a slider writes one register (W); the presets and the wave write all sixteen in a single block write (B), 19 bytes on the wire. Everything here is also reachable from the shell: ucom w pwm.ch3 0xC0.
